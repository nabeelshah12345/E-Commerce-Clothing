# Plan: Checkout Form Implementation (Replace Alert with Form)

## Goal
"Proceed to Checkout" button click karne par:
1. Cart sidebar **close** ho jaye
2. **Centered checkout modal** screen ke beech mein aaye (cart sidebar se independent)
3. Modal mein order details form — name, phone, email, address, city + order summary
4. "Confirm Order" click → validation → success message: "Your order is confirmed! Aapka order confirm ho gaya hai"
5. Cart clear ho jaye, modal close ho jaye

---

## Context

**Existing flow** (`script.js:233-244`):
- Empty cart alert
- `alert()` with total + "Thank you for shopping"

**New UI**:
- Full-screen semi-transparent overlay
- Centered white card (max ~600px) with:
  - Header (title + close X button)
  - Cart items summary (list)
  - Order total
  - Customer details form (name, phone, email, address, city) — all required
  - "Confirm Order" button
- Success screen replaces form on confirmation

---

## Implementation Steps

### 1. Update `proceedToCheckout()` (script.js)
- Cart empty → existing alert
- Else:
  - `toggleCart()` → close sidebar
  - `showCheckoutModal(total)` → open overlay

### 2. New function: `showCheckoutModal(total)`
DOM mein inject karega:
- `<div id="checkoutOverlay" class="checkout-overlay">`
  - `<div class="checkout-modal">`
    - `<div class="checkout-header">` + close button
    - `<div class="checkout-body">` (dynamic content)
      - Items list (cart array map)
      - Order total
      - `<form id="checkoutForm">` with fields
    - `</div>`
  - `</div>`
`</div>`

Form fields (required):
- Full Name — text
- Phone Number — tel
- Email Address — email
- Delivery Address — textarea
- City — text

Buttons:
- Cancel → `closeCheckoutModal()`
- Confirm Order → `confirmOrder(event)`

### 3. New function: `closeCheckoutModal()`
- Overlay ko remove/`display:none` karein
- Cart items original state preserved (or re-render via `renderCart()`)

### 4. New function: `confirmOrder(event)`
- Prevent default
- Validate (HTML5 `required`)
- Clear cart: `cart = []; saveCart(); updateCartCount();`
- Show success screen inside modal:
  - Checkmark icon (✓)
  - "Your order is confirmed!"
  - Personalized message: "Thank you, [Name]!"
  - "Hum aapko delivery details aur updates jald inform kar denge."
  - "Continue Shopping" button → close modal
- Toast notification

### 5. CSS additions (style.css)
- `.checkout-overlay` — fixed, inset 0, z-index 2000, semi-transparent bg (`rgba(0,0,0,0.4)`), flex center
- `.checkout-modal` — white bg, rounded (16px), shadow, max-width 580px, width 92vw, max-h 90vh, overflow-y auto
- `.checkout-header` — flex, padding, border-bottom, close button (transparent, size 24px)
- `.checkout-body` — padding
- `.checkout-items-list` — cart items (image 60x75, name, price, qty, remove btn)
- `.checkout-summary` — total, bold, margin
- `.checkout-form` — grid/flex column, label+input/textarea, button group
- `.checkout-back-btn` / `.confirm-order-btn` — existing `.checkout-btn` colors (or slight variant: confirm primary)
- `.order-success` — centered text, icon 48px green/`#413923`, margin, button
- Mobile: smaller padding, font adjustments
